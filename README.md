# Presentación de Victoria

Web estática lista para Vercel. No necesita dependencias ni compilación.

## Abrir en el ordenador

Abre index.html. Las imágenes y estilos funcionan sin conexión. El enlace al proyecto necesita internet.

## Publicar en Vercel

1. Descomprime esta carpeta y sube su contenido a un repositorio de GitHub.
2. En Vercel, importa ese repositorio como un nuevo proyecto.
3. Elige Framework Preset: Other. Mantén vacíos Build Command y Output Directory. No necesita Install Command.
4. Pulsa Deploy y abre el enlace que devuelva Vercel.

Alternativa, si ya utilizas Vercel CLI: ejecuta `vercel --prod` dentro de esta carpeta.

## Presentación

Usa el menú, las flechas inferiores o las teclas izquierda/derecha. El control superior derecho activa la pantalla completa cuando el navegador lo permite. Pulsa las capturas para ampliarlas y Escape para cerrarlas. El enlace a Solamente Cree abre una pestaña nueva.

El apartado de proyecto muestra solo el enlace y las dos capturas, como se solicitó. No incluye guiones, datos laborales ni instrucciones de grabación. Las estadísticas son las aportadas en las capturas del 21/10/2026. La web lleva noindex como presentación de candidatura, sin seguimiento ni formularios.
